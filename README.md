# Coffee-Sales-Dashboard

## Project Overview

The **Coffee Sales Dashboard** is an interactive Power BI dashboard designed to analyze coffee sales performance across different countries, customer segments, coffee roast types, package sizes, and time periods. It provides a comprehensive view of sales trends and customer behavior, enabling businesses to make informed decisions that improve revenue and optimize sales strategies.

# Dashboard Highlights

### Key Features

- Interactive date timeline for filtering sales by period
- Loyalty Card filter
- Coffee package size filter
- Roast type filter
- Sales trend analysis over time
- Country sales comparison
- Top customer analysis

---

## Sales Over Time

This visual tracks coffee sales over multiple years, allowing users to monitor sales performance and seasonal trends.

The dashboard compares sales across four coffee varieties:

- Arabica
- Excelsa
- Liberica
- Robusta

**Insights**
- Identify seasonal sales fluctuations.
- Compare the performance of different coffee varieties.
- Monitor long-term sales growth.

---

## Sales by Country

Displays total sales generated across different countries.

The dashboard compares sales from:

- United States
- Ireland
- United Kingdom

**Insights**
- Identify the highest revenue-generating country.
- Compare international market performance.
- Support regional sales strategies.

---

## Top 5 Customers

Ranks customers based on total purchase value.

**Insights**
- Identify high-value customers.
- Support customer retention strategies.
- Recognize loyal customers for targeted promotions.

---

## Interactive Filters
